# Vrinda Store Sales Analysis Dashboard

## Project Overview
This project analyzes Vrinda Store sales data using Microsoft Excel to identify sales trends, customer purchasing patterns, and business performance.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Charts and Data Visualization
- Data Analysis

## Project Objectives
- Analyze sales performance and order trends.
- Understand customer purchasing patterns.
- Identify key business insights from sales data.
- Present findings through a visual dashboard.

## Project Files
- `Vrinda Store Data Analysis.xlsx` – Excel workbook containing the sales analysis.
- `PREVIEW OF DASHBOARD.png` – Dashboard preview.
